# 总体架构

## 目标闭环

```text
摄像头输入
    ↓
图像采集与预处理
    ↓
INT8 神经网络推理
    ↓
PS 结果解析
    ↓
HDMI/LED/板卡交互
```

## 模块划分

| 模块 | 主要职责 | 初始实现 |
|---|---|---|
| 输入模块 | 获取摄像头或固定测试图像 | 先支持稳定替代输入 |
| 预处理模块 | 灰度化、缩放、定点化 | 先保证输入格式一致 |
| PL 加速器 | INT8 乘加、卷积或全连接 | 从单个 MAC 单元开始 |
| PS 控制模块 | 启动任务、传递数据、读取结果 | 先实现最小控制闭环 |
| 输出模块 | 显示类别、置信度和控制状态 | 先用 LED 或简单显示验证 |

## 版本策略

1. 国三基础版：固定输入或稳定替代输入 + 小型 INT8 CNN + 至少一个 PL 核心 + 可测量结果。
2. 国二提交版：摄像头输入 + PL/PS 闭环 + 板卡交互 + 软件基线对比 + 资源/时延/精度证据。
3. 国一强化版：摄像头实时输入 + 流水线 + 片上复用 + 可配置能力 + 异常恢复 + 自动化验证和可复用 Skill。

详细分级设计见 [[国三国二国一设计路线|国三—国二—国一设计路线]]。
