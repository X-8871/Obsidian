# 接口设计

## 当前接口链路

```text
输入数据 → 预处理 → PL 推理 → PS 读取结果 → 交互输出
```

## 接口待定项

| 接口 | 当前方案 | 必须确认 |
|---|---|---|
| 摄像头到 FPGA | 待定 | MIPI、HDMI、并口或其他接口 |
| PS 到 PL | 待定 | AXI-Lite、AXI-Stream 或 BRAM |
| PL 任务控制 | start/busy/done | 时序和寄存器定义 |
| 识别结果 | 类别编号 + 置信度 | 数据位宽和有效标志 |
| 输出交互 | HDMI、LED 或板载外设 | 先选择一个稳定输出 |

## 设计约束

- 先定义输入、输出、时钟、复位和有效信号，再扩展功能。
- 每个接口都要有仿真或上板证据。
- 不在接口未确认前锁定复杂摄像头方案。
