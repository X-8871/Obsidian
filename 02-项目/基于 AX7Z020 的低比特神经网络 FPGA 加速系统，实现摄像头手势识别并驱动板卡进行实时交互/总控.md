## 1. AI 接手协议

1. 先读取本文件，再读取 [[项目进程]]、[[项目总览]] 和当前相关的 `08-PlanMind` 计划。
2. 以用户当轮明确指令为最高优先级；本文件记录的是稳定事实，不替代用户的新要求。
3. 不能把“计划完成”写成“项目完成”。只有实际运行结果、截图、报告、代码或视频能够证明的内容，才可在 [[项目进程]] 中标记为完成。
4. 遇到硬件型号、接口、竞赛规则等未确认信息，标记为“待核对”，不得自行补全。
5. 修改工程代码前，先检查当前文件和已有改动；修改后说明改动范围和验证结果。
6. 每轮工作结束时，更新 [[项目进程]]：完成项、证据、未完成项、阻塞点和下一步。
7. 当前只预先制定到 2026-09-10 的日计划；9 月 11 日以后依据 9 月 10 日复盘结果再展开。

## 2. 项目稳定事实

| 项目 | 当前信息 |
|---|---|
| 项目名称 | 基于 AX7Z020 的低比特神经网络 FPGA 加速系统，实现摄像头手势识别并驱动板卡进行实时交互 |
| 参赛方向 | FPGA 创新设计赛道中的自主选题赛道；组别待报名确认 |
| 目标平台 | ALINX AX7Z020，具体器件型号需以板卡实物和工程配置为准 |

| 暂定类别 | 握拳、手掌、数字一、数字二、数字三，共 5 类静态手势 |
| 当前队伍 | 用户与指导老师；其他队员以用户后续确认为准 |
| 作品目标 | 提交前达到国三与国二之间；初审通过后强化到国二与国一之间 |
| 论文安排 | 考研结束后再考虑，当前不占用作品开发主线 |
| 当前阶段 | 2026-09-02 至 2026-09-10：FPGA 基础能力与工程环境打底 |
| 报名状态 | 尚未报名；需要准备选题方向和作品简介 |

### 竞赛提交要求摘要

- 必须提交完整工程、源码、仿真/验证结果、综合与实现报告、上板工程、运行脚本和实测输出。
- 工程目录和文件名使用英文、数字、下划线或连字符；中文只用于文档正文。
- 需要保存大模型协作记录，并将可复用经验整理为 `skill/` 技能包。
- 评分核心为创新与应用、性能与资源、功能完整性、AI 协作与 Skill、文档与复现；具体权重见 [[01-竞赛材料/赛道规则|赛道规则]]。

## 3. 当前系统边界

### 必须完成

- AX7Z020 工程能够建立、编译和上板运行。
- 完成一个可解释的低比特神经网络推理链路。
- 至少实现摄像头或固定图像输入、识别结果输出和板卡交互中的可演示闭环。
- 提供精度、延迟、资源占用和运行稳定性的基本证据。
- 形成报名简介、作品说明、演示视频和答辩材料。

### 暂不扩张

- 不同时开发多个模型或多个应用场景。
- 不在基础版本阶段追求复杂摄像头算法、复杂 UI 或大模型。
- 不在作品提交前强行写论文。
- 不在没有测量数据前宣称“实时”“低功耗”或“显著加速”。

## 5. 当前工作优先级

1. 核对 AX7Z020 实物型号、Vivado 器件型号、摄像头和显示接口。
2. 跑通计数器、复位、状态机、RAM/ROM 和最小仿真流程。
3. 用 Python 建立 INT8 乘加参考结果，再实现 RTL 版本并逐项比对。
4. 准备 AMD FPGA 创新设计赛道的选题方向和作品简介。
5. 2026-09-10 进行第一次阶段复盘，只据真实证据决定下一阶段任务。
