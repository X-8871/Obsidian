# 🎯 PlanMind 目标与计划中心

> 本目录由 PlanMind Web 代理系统连接与同步，实现了从**年度目标 → 月度目标 → 周目标 → 今日计划**的逐级拆解与实时双向联动。

> **使用理念**：PlanMind 不是对未来的刚性承诺，而是一套让目标更可能发生的反馈系统。它以终为始进行反向设计，用少而聚焦的目标控制范围，用 If-Then 行动降低对意志力的依赖，再通过日、周、月和阶段复盘持续校准。完整说明见：[[08-PlanMind/00-计划-目标-行动-复盘理念|计划—目标—行动—复盘理念]]。
