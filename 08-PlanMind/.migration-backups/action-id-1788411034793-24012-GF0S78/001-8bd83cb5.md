# 2026 年度目标

> **主轴**：以 FPGA 竞赛作品为近期主线，以 9 月基础能力达标为前置条件，同步保护考研准备，建立稳定的学习—项目—复盘节奏。

关联作品：[[02-项目/基于 AX7Z020 的低比特神经网络 FPGA 加速系统，实现摄像头手势识别并驱动板卡进行实时交互/项目总览|AX7Z020 低比特视觉指令识别与边缘控制系统]]

## 🎯 主线目标

- [ ] **作品目标**：完成 AX7Z020 低比特视觉指令识别与边缘控制系统；作品提交前达到国三与国二之间，初审通过后再强化到国二与国一之间
  - 完成标准：提交版本具备可运行工程、真实板卡演示、实验指标和复现材料；初审后若继续强化，新增功能必须有优化前后对比证据。
- [ ] **能力目标**：2026 年 9 月 30 日前达到基础 FPGA 独立开发能力，能够独立编写、仿真、综合、上板和解释作品中的关键模块
  - 完成标准：不看原代码独立完成至少一个 RTL 模块，仿真通过、综合有报告、上板有照片/串口记录，并能口头解释时序和边界。
- [ ] 嵌入式与 MCU：持续提升应用开发、通信和项目落地能力
  - 完成标准：2026 年内完成至少 2 个可运行的 MCU/通信小实验，每个都有源码、运行结果和一页复盘；不能只以看教程计入。
- [ ] 考研准备启动：数学+英语基础打牢，推进东南大学信息科学与工程学院 085400 目标
  - 完成标准：完成考研科目、资料和周时间块配置；9—12 月每周至少留下 5 次数学/英语学习记录，并完成至少 2 次阶段测验。
- [ ] 建立稳定的年度学习、项目和复盘节奏
  - 完成标准：每周至少 1 次周复盘、每月 1 次月度校准；年度内不得连续 2 周没有复盘记录。

## 🌿 支线目标

- [ ] 智能体应用：明确实践方向，完成一个小型 AI 应用
  - 完成标准：完成一个能运行的最小应用，包含 README、运行截图或演示和一次复盘；不以调研链接数量计入。
- [ ] 健身：保持每周 4 练，全年无断更超过 2 周
  - 完成标准：每周记录 4 次训练；若某周未达标，下一周补足并记录原因，不得连续两周没有训练记录。
- [ ] 维护课程成绩与个人事务
  - 完成标准：课程作业和重要事务在截止日前完成；任何逾期事项必须在 7 天内补交或记录处理方案。

## 🧩 作品与能力双目标

### 作品目标

- [ ] 完成摄像头或固定图像输入、FPGA 预处理、INT8 CNN 推理和 HDMI/LED/UART 输出链路
  - 完成标准：输入经过预处理进入模型，输出类别能在 UART、LED 或显示端观察到；至少完成一个真实板卡闭环，固定图像可作为摄像头故障时的保底路径。
- [ ] 完成软件参考模型、FPGA 结果比对、准确率、延迟、吞吐率、资源和时序记录
  - 完成标准：同一输入在软件和 FPGA 侧输出一致性可复测，并形成含测试条件、次数、时钟和版本的指标表。
- [ ] 提交源码、模型参数、仿真结果、上板记录、报告、视频和复现说明
  - 完成标准：提交清单全部勾选，第三方按 README 能从零完成工程构建、下载和演示。

### 能力目标

- [ ] 能独立完成计数器、状态机、FIFO、RAM、UART、INT8 乘加等基础 RTL
  - 完成标准：每类模块至少有一个可打开的源文件和测试平台；计数器、FSM、RAM/ROM、INT8 MAC 有波形或 Python 对照证据。
- [ ] 能独立使用 Vivado 完成约束、综合、实现、时序和资源分析
  - 完成标准：从空工程完成添加源文件、加入 XDC、综合、实现、查看时序和资源报告，并能指出一项关键结果。
- [ ] 能解释 PS/PL 分工、AXI 数据流、定点量化和作品中所有关键模块
  - 完成标准：不看笔记画出数据流图，并用 5 分钟说明每个模块的输入、输出、时钟、复位和失败边界。
- [ ] 9 月内完成一次不依赖 AI 和队友的核心模块重写与上板验证
  - 完成标准：独立重写的模块在仿真中通过边界测试，并在 AX7Z020 上产生可观察的 LED、串口或其他输出。

## 🚫 本年度主动回避

- [ ] 不把 nanoGPT 继续扩展为大型语言模型工程；它只作为低比特推理技术积累
  - 遵守标准：2026 年不新增 nanoGPT 大功能；所有相关工作必须直接服务于量化、推理或硬件部署。
- [ ] 不在提交前堆叠语音、视觉、机器人等多条主线
  - 遵守标准：提交前只维护本项目一条主线；新增方向记录为“暂缓”，不得进入当前周/月计划。
- [ ] 不在基础闭环稳定前追求国一复杂度
  - 遵守标准：国三基础闭环未具备仿真、上板和指标证据前，不开始高风险扩展功能。
- [ ] 不让 FPGA 竞赛挤占 2027 年考研冲刺阶段的核心复习容量
  - 遵守标准：进入考研冲刺阶段后，竞赛只保留必要维护，不新增大模块；每月复盘一次时间占用。
