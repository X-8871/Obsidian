# 计划总览

计划按“年度 → 月度 → 周度 → 日度”逐层拆解。每一级都分为主线和支线，主线负责推动长期目标，支线负责维持其他重要事项。

## 当前计划

- 年度：[[plan/2026/00-年度总计划|2026 年度总计划]]
- 月度：[[plan/2026/08-八月/00-月计划|2026 年 08 月计划]]
- 周度：[[plan/2026/08-八月/2026-W34/00-周计划|2026 W34 周计划]]
- 今日：[[plan/2026/08-八月/2026-W34/日计划/2026-08-17|2026-08-17 日计划]]

## 使用规则

1. 先在年度计划确定方向，再逐层拆到月、周、日。
2. 每个层级只保留少量主线任务，支线任务不要挤占主线时间。
3. 周计划负责安排一周任务，日计划只写当天真正要做的事。
4. 新建计划时，复制 `[[plan/模板/计划模板|计划模板]]`，再修改标题、时间和上下级链接。
