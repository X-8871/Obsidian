# 第一章：model.py 模型骨架

## 总体数据流

```text
Token ID
  ↓ wte：Token Embedding
Position ID
  ↓ wpe：Position Embedding
两者相加
  ↓ dropout
6×Block
  ↓ ln_f：最终 LayerNorm
  ↓ lm_head
logits
```

## 关键形状

- `idx`：`(B,T)`，B 是批次大小，T 是序列长度。
- `wte(idx)`：`(B,T,C)`，C 是特征维度，本项目 C=384。
- `wpe`：通常是 `(block_size,C)`，不是 `(T,V)`；V 是词表大小。
- `lm_head(x)`：`(B,T,V)`，V=65，表示每个位置对 65 个字符的分数。

## 已掌握与易错点

- 训练时有 `targets`，模型返回 logits 和 loss。
- 推理时没有 targets，只取最后一个位置的输出，避免重复计算前面位置的 `lm_head`。
- Position Embedding 的最后一维应与 C 对齐，不是与 V 对齐。
