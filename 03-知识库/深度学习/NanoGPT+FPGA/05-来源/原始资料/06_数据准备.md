# 第六章：数据准备

## 数据流

~~~text
input.txt 原始文本
  ↓ 建立字符表
stoi：字符 → 编号
itos：编号 → 字符
  ↓ 编码
所有字符编号
  ↓ 90%/10% 划分
train.bin / val.bin
  ↓ 训练时随机选择起点
x：连续 T 个 Token
targets：右移一个位置的 Token
~~~

## 文件作用

- input.txt：Shakespeare 原始字符文本。
- train.bin：训练集 Token 编号二进制文件。
- val.bin：验证集 Token 编号二进制文件。
- meta.pkl：保存 stoi 和 itos，保证编码和解码一致。
- uint16：当前词表只有 65 个字符，使用 16 位无符号整数已经足够并能节省空间。

## 为什么随机选择起点

每次从文本中随机取连续的 block_size 个字符，可以得到不同训练窗口，避免模型每次只学习固定位置；targets 是同一窗口向右移动一位后的正确答案。
