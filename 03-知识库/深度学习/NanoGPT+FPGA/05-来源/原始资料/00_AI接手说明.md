# NanoGPT 学习项目：AI 接手说明

## 一、用户背景

- 用户有神经网络、CNN（Convolutional Neural Network，卷积神经网络）、PyTorch 和 C 语言基础。
- Python 阅读能力较弱，尤其需要帮助理解类、函数、字典、切片、张量操作、文件路径和命令行参数。
- 已连续学习 nanoGPT 七天，但知识点较零散，需要先建立完整数据流，再进入 FPGA 部署。
- 用户喜欢短段讲解、数据流图、生活类比、真实代码、PowerShell 命令和实验结果。
- 用户要求所有英文缩写第一次出现时说明英文全称、中文含义和在项目中的作用。

## 二、项目目标

```text
文本 → Token ID → Embedding → 6×Transformer Block
     → LayerNorm → lm_head → 下一个 Token ID → 字符
     → INT8/Q30 → FPGA/PS+PL → 板上 Token 输出
```

近期目标：在 2026 年 8 月 10 日继续完成 SD 卡脱机启动、UART、多 Token、稳定性、性能和 Python Q30 对齐验收；若有剩余时间，再从打开 Vivado 开始用 GUI 复现一次部署流程。

## 三、必须遵守的教学方法

每次只讲一个模块：

```text
总框架位置 → 真实文件 → 输入输出形状 → 代码解释
→ 用户复述 → 逐点评价“对/错/补充” → 改代码/运行验证
```

- 只基于项目真实代码，不引入无关论文、视频或外部项目。
- 先框架后细节，避免一次讲太多。
- 解释抽象概念时使用图示、形状和类比。
- 不要把“Python 自一致性”说成“FPGA 已经通过”。
- PowerShell 命令必须使用：`& "D:\FPGA\NanoGPT\venv-gpu\Scripts\python.exe"`。
- 训练和实验使用 `venv-gpu`，不要切换到系统 Python。
- 每次完成重要实验后提醒打包工程。

## 四、已完成内容

用户已经学习并复述过：

1. `model.py` 骨架：Token Embedding、Position Embedding、6 层 Block、最终 LayerNorm 和 `lm_head`。
2. Transformer Block：Attention、MLP、残差连接和 LayerNorm。
3. Self-Attention：QKV、QKᵀ、缩放、Softmax、AV、多头拼接和输出投影。
4. `train.py`：targets、交叉熵、展开、backward、grad、optimizer、GradScaler 和学习率调度。
5. `sample.py`：最后一个位置、temperature、Top-k、随机采样和 Token 解码。
6. 数据准备：`train.bin`、`val.bin`、`meta.pkl`、`stoi`、`itos` 和随机窗口。
7. 量化链路：W8A8、激活张量、scale、INT8、Q30、动态/固定 scale 和 Python 阶段比较。
