# 🖥️ 云服务器连接与运维指南 (模板)

> [!NOTE]
> 本文件为云端服务器、物理主机与网络环境的标准化连接与运维模板。可根据实际服务器信息进行替换。

---

## 一、 服务器基础连接信息

| 配置项 | 参数值 | 说明 |
| :--- | :--- | :--- |
| **服务器名称/用途** | 生产主节点 / 测试机 | 业务核心服务 |
| **公网 IP (Host)** | `x.x.x.x` | 远程连接地址 |
| **SSH 端口** | `22` (或自定义端口) | 安全端口 |
| **登录用户** | `root` / `ubuntu` | 常用非特权/特权账号 |
| **认证方式** | SSH Key / 密钥对 | 推荐免密密钥登录 |
| **本地密钥路径** | `~/.ssh/id_rsa` | 本地存储私钥位置 |

---

## 二、 常用一键连接命令

### 1. SSH 直接登录
```bash
ssh -i ~/.ssh/your_key.pem -p 22 root@x.x.x.x
```

### 2. VSCode / IDE 远程配置 (`~/.ssh/config`)
```ssh
Host my-cloud-server
    HostName x.x.x.x
    User root
    Port 22
    IdentityFile ~/.ssh/your_key.pem
```

---

## 三、 常用服务运维命令与目录拓扑

### 1. 核心目录与路径
- **项目部署根目录**：`/data/apps/` 或 `/www/wwwroot/`
- **日志目录**：`/var/log/` 或 `/data/logs/`
- **Docker 编排配置**：`/data/docker-compose/`

### 2. 常用服务启停管理
```bash
# 查看服务状态
systemctl status [服务名]

# 重启服务
systemctl restart [服务名]

# 查看实时日志
journalctl -u [服务名] -f -n 100
```

---

## 四、 常见网络与排障 Q&A

- **Q: 无法连接 SSH？**
  - 检查云厂商控制台安全组（Security Group）是否已放行对应端口。
  - 检查本地网络及公钥权限（Linux/Mac 下 `chmod 600 key.pem`）。
