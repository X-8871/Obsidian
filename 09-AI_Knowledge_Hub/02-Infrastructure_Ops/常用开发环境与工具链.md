## 六、 核心调用注意与避坑指南 (Operational Caveats)

1. **磁盘防爆满准则**：
   - C 盘剩余 42G 偏低，任何大型数据集、预训练大模型文件（如 `.safetensors`、`.bin`）或深度学习依赖，**必须强行保存到 D 盘**。
2. **Python 别名调用**：
   - 必须使用 `python script.py`，系统无 `python3` 命令；
   - ESP32 构建**必须**指定专用 Python 路径：`C:/Espressif/python_env/idf5.5_py3.11_env/Scripts/python.exe`。
3. **终端编码与空格转义**：
   - Git Bash 环境下操作包含中文与空格的路径时，**必须用双引号包裹**。
