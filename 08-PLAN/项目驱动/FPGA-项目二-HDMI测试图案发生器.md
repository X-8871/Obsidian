# 🏗️ 项目二：HDMI 测试图案发生器（5 天）

> 原则：不学视频协议，直接抄 ALINX 的 HDMI 例程改

---

## 🎯 项目目标

AX7035B 输出 HDMI 信号到显示器，显示各种测试图案，能用按键/拨码/串口控制。

**最终能演示什么：**
1. 显示器显示 640×480 @60Hz 画面
2. 按键切换 6 种图案：纯色 → 彩条 → 渐变 → 棋盘格 → 网格 → 画中画
3. 拨码开关调参数（颜色、分辨率、滚动速度）
4. 串口远程切换图案和调参数

## 🗓️ Day 1（08-27）：让显示器亮起来

### 最终目标
不管显示什么，显示器上出现画面。

### 一步一步怎么做

**第 1 步：找到 AX7035B 的 HDMI 例程**
- 来源：开发板附带的光盘 / ALINX 官网 / 百度网盘
- 搜 "AX7035B HDMI 例程" 直接下载
- 例程名一般是 `ax7035b_hdmi_demo` 或 `hdmi_test`

**第 2 步：直接打开工程，烧录**
- 不修改任何代码
- 打开 Vivado 工程
- 生成 bitstream
- 连接：
  - 板子 HDMI 口 → HDMI→VGA 转换器 → 显示器 VGA 线
  - 转换器的 USB 供电线插到板子 USB 口或电脑
- 烧录

**第 3 步：看显示器有没有画面**
- 有 → 跳到第 4 步
- 没有 → 排查：
  - 转换器 USB 供电插了吗？
  - 显示器切换到 VGA 输入了吗？
  - 板子 HDMI 输出口是靠近电源的那个吗？
  - 试不同的 HDMI 线

**第 4 步：通读工程结构**
- 打开工程，找到以下文件，回答三个问题：
  - 哪个文件是生成时钟的？（文件名一般带 `clk` 或 `clock`）
  - 哪个文件是 HDMI 时序的？（文件名一般带 `hdmi` 或 `timing`）
  - 哪个文件是画面内容的？（文件名一般带 `pattern` 或 `color`）

## 🗓️ Day 2（08-28）：按键切换 6 种图案

### 最终目标
按键按一次，切换一种图案，至少 6 种。

### 一步一步怎么做

**第 1 步：找到图案生成的代码**
- 在例程里找到生成 RGB 颜色的地方
- 一般长这样：
```c
// h_counter = 当前像素的行位置（0-639）
// v_counter = 当前像素的列位置（0-479）
if (h_counter < 320)
    R=255, G=0, B=0;    // 左半边红色
else
    R=0, G=0, B=255;    // 右半边蓝色
```

**第 2 步：理解代码逻辑**
- `h_counter` 和 `v_counter` 就是当前像素的坐标
- 根据坐标判断每个像素的颜色 = 图案生成

**第 3 步：把项目一的按键接口搬过来**
- 把 Day 1 的按键读取代码复制过来
- 按键按一次 → `pattern_index++`
- 根据 `pattern_index` 选择不同的图案逻辑

**第 4 步：实现 6 种图案**

| 图案 | 怎么实现 |
|:----|:---------|
| ① **纯色** | 全屏 R=255,G=0,B=0（红），按键切换 R/G/B/白 循环 |
| ② **彩条** | h_counter / 80 → 8 种颜色，每种颜色 80 像素宽 |
| ③ **渐变** | R = h_counter * 255 / 640，从左到右从黑到红渐变 |
| ④ **棋盘格** | (h_counter/32 + v_counter/32) % 2 == 0 → 白，否则黑 |
| ⑤ **网格** | h_counter % 32 == 0 或 v_counter % 32 == 0 → 黑线，否则白 |
| ⑥ **画中画** | 中间 200×200 区域显示另一种图案，周围显示原图 |

**第 5 步：综合 + 烧录 + 测试**
- 按键切换，每种图案都正常显示

### 今天产出物
- [ ] 按键切换 6 种图案
- [ ] 能看懂例程的时序代码

## 🗓️ Day 3（08-29）：DDR3 帧缓存

### 最终目标
图案先写入 DDR3 内存，再从内存读出显示。

### 一步一步怎么做

**第 1 步：找到 DDR3 控制器**
- 例程里一般已经带了 DDR3 控制器（MIG IP 核）
- 在 Block Design 里找叫 `mig_7series` 或 `ddr3` 的模块
- 找到它的读写接口（一般有 `app_addr`、`app_wdf_data`、`app_rd_data`）

**第 2 步：理解帧缓存概念**
- 帧缓存 = 在 DDR3 里划一块区域存一帧图像
- 写：把图案数据写到 DDR3 的某个地址
- 读：HDMI 输出时，从 DDR3 读像素数据
- 这就像电脑的显存（VRAM）

**第 3 步：修改代码，使用帧缓存**
- 写一个简单的纯色帧到 DDR3
- 修改 HDMI 输出代码，从 DDR3 读数据而不是直接生成
- 显示器显示从 DDR3 读出的内容

**第 4 步：按键切换时更新帧缓存**
- 按按键 → 新图案写入 DDR3 → HDMI 从 DDR3 读出显示
- 确认切换时不会闪屏

## 🗓️ Day 4（08-30）：交互控制 + 参数调节

### 最终目标
拨码和串口也能控制图案和参数。

### 一步一步怎么做

**第 1 步：拨码开关控制分辨率**
- 拨码 00 → 640×480
- 拨码 01 → 800×600
- 拨码 10 → 1024×768（先试，转换器可能不支持）
- 需要修改 HDMI 时序参数

**第 2 步：串口远程控制**
- 把项目一的串口模块搬过来
- 串口命令：
  - `pattern 3` → 切换到第 3 种图案
  - `color red` → 主色调改成红色
  - `speed 3` → 渐变滚动速度 3

**第 3 步：三种控制方式打通**
- 按键切换图案
- 拨码调参数
- 串口远程控制
- 确认三种方式不冲突

- [ ] 三种控制方式（按键/拨码/串口）全部打通

|:----------|:-------|
