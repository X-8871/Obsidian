## 📦 最终产出

一个 HDMI 测试图案发生器：
- 显示器显示 640×480 @60Hz 画面
- 按键切换 6 种测试图案：纯色 → 彩条 → 渐变 → 棋盘格 → 网格 → 画中画
- 拨码开关控制参数（颜色、分辨率、滚动速度）

4. **如果亮了，通读工程结构**

## 🗓️ Day 2：用按键切换图案

**今天目标：理解图案怎么生成的，然后自己改**

### 任务

1. **找到图案生成代码**
   - 在例程里找到生成 RGB 颜色的地方
   - 通常是一个 `h_counter`（行计数）和 `v_counter`（场计数）决定每个像素的颜色

2. **理解图案生成逻辑**
   ```c
   // 伪代码，看懂逻辑
   if (h_counter < 320)      // 左半边
       R = 255, G = 0, B = 0;   // 红色
   else                       // 右半边
       R = 0, G = 0, B = 255;   // 蓝色
   ```
   - 这就是最简单的"左右分屏"图案

3. **加按键切换图案**
   - 把项目一的按键接口搬过来
   - 按键按一次 → 切换一种图案
   - 至少 6 种图案：

   | 图案 | 逻辑 |
   |:----|:-----|
   | 纯色（红/绿/蓝/白 循环） | 全屏固定颜色，按键切换颜色 |
   | 彩条 | 竖条，每 1/8 宽度一种颜色 |
   | 渐变 | 颜色从 0→255 线性变化 |
   | 棋盘格 | 行列交替黑白 |
   | 网格 | 画横线和竖线 |
   | 画中画 | 中间一个小方块显示另一种图案 |

- [ ] 能看懂例程的时序代码

## 🗓️ Day 3：DDR3 帧缓存接入

**今天目标：从"直接生成图案"升级到"先生成到内存，再显示"**

### 任务

1. **找到例程里的 DDR3 控制器**
   - ALINX 例程一般已经带了 DDR3（MIG IP 核）
   - 找到 DDR3 读写接口

2. **理解帧缓存的概念**
   - 存：把一帧图像的数据写到 DDR3 的某个地址
   - 读：HDMI 输出时，从 DDR3 读像素数据
   - 这就是"帧缓存 frame buffer"

3. **实现：图案写入 DDR3 → 从 DDR3 读出显示**
   - 先写一个简单的纯色帧到 DDR3
   - 显示出来
   - 再改成按键切换时，把新图案写入 DDR3

## 🔧 技术提示（卡了再看）

<details>
<summary>HDMI 时序 640×480 @60Hz 参数（卡了再点开）</summary>
H_total = 800, H_active = 640, H_front = 16, H_sync = 96, H_back = 48
V_total = 525, V_active = 480, V_front = 10, V_sync = 2, V_back = 33
时钟频率 = 25.175 MHz（AX7035B 一般用 25MHz 也行）
</details>

<details>
<summary>帧缓存地址计算（卡了再点开）</summary>
一帧 640×480 像素，每个像素 24bit（RGB888）
一帧大小 = 640 × 480 × 3 = 921,600 bytes ≈ 0.9 MB
AX7035B DDR3 一般有 256MB，随便放
</details>
