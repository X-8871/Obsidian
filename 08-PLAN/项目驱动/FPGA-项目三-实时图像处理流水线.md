# 🏗️ 项目三：实时图像处理流水线（7 天）

> 目标：在项目二的基础上，实现实时图像处理流水线
> 项目二生成图案 → HLS 图像处理核 → 处理结果 HDMI 输出
> 这是 FPGA 大赛"纯图像处理管线"方向的雏形

---

## 📦 最终产出

一个完整的实时图像处理流水线：
- 输入：项目二生成的测试图案
- 处理：灰度转换 → 边缘检测 → 模糊 → 色彩增强
- 输出：按键切换各级处理效果，显示器实时查看
- 串口可调参数（阈值、模糊强度等）

## 🗓️ Day 1：RGB → Gray 灰度转换

**今天目标：写第一个 HLS 图像处理核，看到效果**

### 任务

1. **从项目二复制工程**，改名 `image_pipeline`

2. **写 HLS 灰度转换核**
   ```c
   // 公式：Gray = 0.299*R + 0.587*G + 0.114*B
   // 用定点数或整数实现，不用浮点
   Gray = (R*77 + G*150 + B*29) >> 8;  // 整数近似
   ```

3. **集成到 HDMI 管线**
   - 从 DDR3 读像素 → 灰度转换 → DDR3 写回
   - 按键切换：原图 / 灰度图

4. **看效果**
   - 显示器上图案变成灰度，确认正确

### 今天产出物

- [ ] 按键切换原图/灰度
- [ ] HLS 灰度核综合通过

## 🗓️ Day 2：Sobel 边缘检测

**今天目标：写 Sobel 算子，看到边缘检测效果**

### 任务

1. **写 HLS Sobel 核**
   - 3×3 卷积核，Gx 和 Gy
   - 需要行缓存（line buffer）来存 3 行像素
   - 搜 "Vitis HLS Sobel example" 找参考

2. **理解行缓存**
   - 因为 Sobel 需要 3×3 邻域，所以需要存 3 行数据
   - 用 HLS 的 `LineBuffer` 或 `hls::Window` 实现

3. **集成到管线**
   - 原图 → 灰度 → Sobel → 显示
   - 按键切换：原图 / 灰度 / 边缘

### 今天产出物

- [ ] 显示边缘检测结果
- [ ] HLS Sobel 核综合通过

## 🗓️ Day 3：均值滤波 + 高斯模糊

**今天目标：实现两种滤波效果**

### 任务

1. **写 HLS 均值滤波核**
   - 3×3 均值：9 个像素求和再除以 9
   - 也用行缓存

2. **写 HLS 高斯模糊核**
   - 3×3 高斯核：[[1,2,1],[2,4,2],[1,2,1]] / 16
   - 比均值滤波更平滑，边缘保留更好

3. **集成到管线**
   - 按键切换：原图 / 灰度 / 边缘 / 均值滤波 / 高斯模糊

### 今天产出物

- [ ] 两种滤波效果正常显示
- [ ] 理解行缓存的工作方式

## 🗓️ Day 4：流水线串联 + DATAFLOW 优化

**今天目标：把多个处理级串联成流水线**

### 任务

1. **串联处理流水线**
   ```
   原图 → 灰度 → 均值滤波 → Sobel → 输出
   ```
   - 每一级独立，用 `hls::stream` 连接
   - 不是先处理完一帧再下一帧，而是像素级流水

2. **加 DATAFLOW pragma**
   ```c
   #pragma HLS DATAFLOW
   ```
   - 让各级并行执行

3. **对比性能**
   - 没加 DATAFLOW 的帧率
   - 加了 DATAFLOW 的帧率
   - 看综合报告里的 II（initiation interval）

### 今天产出物

- [ ] 多级流水线串联成功
- [ ] 知道 DATAFLOW 提升了多少

## 🗓️ Day 5：可调参数 + 交互控制

**今天目标：让用户能调参数**

### 任务

1. **Sobel 阈值可调**
   - 串口发 `edge_thresh 50` → 设置边缘检测阈值
   - 低于阈值的边缘不显示

2. **模糊强度可调**
   - 高斯模糊核大小可切换：3×3 / 5×5
   - 5×5 更模糊，但消耗更多资源

3. **色彩增强**
   - 饱和度调节（RGB→HSV→调整→RGB）
   - 串口发 `saturation 1.5` → 饱和度增加 50%

### 今天产出物

- [ ] 串口可调 Sobel 阈值
- [ ] 串口可调模糊强度

## 🗓️ Day 6：性能优化 + 资源分析

**今天目标：优化到能跑 60fps（如果可能）**

### 任务

1. **分析综合报告**
   - 当前用了多少 LUT / DSP / BRAM？
   - 哪一级是瓶颈？

2. **优化瓶颈级**
   - 加 PIPELINE II=1
   - 减少 BRAM 访问次数
   - 优化行缓存大小

3. **帧率测试**
   - 640×480 @60fps 需要每像素 26ns 内处理完
   - 看综合报告的 Latency 是否达标
