## 🔧 硬件平台

### 主开发板：ALINX AX7035B

| 参数      | 规格                                                            |
| :------ | :------------------------------------------------------------ |
| FPGA 芯片 | **Xilinx Artix-7 XC7A35T**                                    |
| 封装      | **FGG484ABX2229**                                             |
| LUT     | ~20,800                                                       |
| DSP48E1 | **90 个**                                                      |
| BRAM    | 50 块（~1.8Mb）                                                  |
| 板载时钟    | **50MHz**                                                     |
| 板载内存    | DDR3（一般 256MB）                                                |
| 板载接口    | HDMI 输出 ×1（仅HDMI_O）、HDMI 输入 ×0、千兆以太网、UART-USB、LED×4、按键×4、拨码×4 |

### 显示器

| 参数   | 规格                       |
| :--- | :----------------------- |
| 接口   | VGA（无直接 HDMI 输入）         |
| 连接方式 | HDMI→VGA 有源转换器（带 USB 供电） |

## ⚠️ 注意事项

- 板子 HDMI 输出口只有 **HDMI_O**（HDMI 输出，无输入）
- 显示器是 VGA 接口，需要用 **HDMI→VGA 有源转换器**（带 USB 供电）
- Vivado 工程文件建议放在 `D:\FPGA\Project\` 下，不要放在 C 盘，避免空间不足
- 每完成一个项目，把工程文件整理到对应目录，并备份
