# 考研北邮与竞赛大计划

> [!important] 一句话主线
> **用竞赛战绩为考研复试和联系导师铺路**：竞赛 → 作品 → 复试弹药 → 心仪导师课题组。

## 目标一：FPGA 大赛（2026，10 周拆解）

> [!tip] 核心策略
> 以 **"作品完成度优先"** 组织学习：不先学完再参赛，而是"边做作品边学"。队友分工 + 选完成度高的题目 + 找老师要资源 = 三个减压杠杆。

| 周 | 时间 | 任务 | 产出 |
|---|---|---|---|
| 第 1 周 | 8.17-8.23 | **报名**、组队、装环境、HDMI 跑通、**HLS 矩阵乘入门** | 队伍就位 + 环境就绪 + 矩阵乘基础 |
| 第 2 周 | 8.24-8.30 | HLS 矩阵乘优化（tiling/pipeline/axi-stream）→ 综合通过 + **AX7035B 以太网 IP 学习** | HLS MatMul 核就绪 |
| 第 3 周 | 8.31-9.6 | **Zynq PS-PL 通信入门**（AXI DMA） + **极简 Transformer 训练**（2 层单头 d_model=32） | Zynq 最小系统跑通 + 模型训练完成 |
| 第 4 周 | 9.7-9.13 | 赛题发布 → **定题**（双板协同方案）、画系统框图、分模块 | 一页纸方案 |
| 第 5 周 | 9.14-9.20 | AX7035B：HDMI 输入+以太网发送系统联调 / AX7020：HLS MatMul 核 + ARM 推理流水线 | 各模块单测通过 |
| 第 6 周 | 9.21-9.27 | PS-PL 通信打通 + 双板以太网通信联调 + 模型量化 INT8 | 双板通信通 |
| 第 7-8 周 | 9.28-10.11 | 全系统联调：HDMI 输入→AX7035B→以太网→AX7020 推理→结果返回→HDMI 叠加显示 + **写初赛文档** | 可演示作品 |
| 第 9 周 | 10.12-10.18 | 演示视频 + PPT + 预答辩演练 | 初赛材料提交 |
| 第 10 周 | 10.19-10.25 | 打磨 bug、优化细节、准备技术问答 | 决赛心态 |

**技术路线**：双板协同——AX7035B（HDMI 前端）+ AX7020（Zynq-7020 Transformer 加速器）
- AX7035B：HDMI 输入捕获 → 帧缓存 → 千兆以太网发送 → 接收结果 → HDMI 叠加显示
- AX7020（Zynq-7020）：以太网接收帧 → ARM 预处理 → PL（HLS 矩阵乘核）加速 Transformer 推理 → ARM 做 Softmax/LayerNorm → 返回结果
- 模型：极简 Transformer（2 层、单头、d_model=32）+ INT8 量化
- 你的角色：模型训练/量化 + HLS 矩阵乘加速器 + ARM 推理流水线 + 系统集成
- 队友：硬件岗（Verilog 胶水代码/以太网驱动/板级调试）+ 系统岗（文档/视频/答辩）

> [!warning] 减险开关（含止损点）
> **止损点 1（9 月中）**：HLS 矩阵乘 DSP 消耗超 180/220 → 缩小矩阵维度，降级为纯 CNN 加速器
> **止损点 2（9 月底）**：双板以太网通信没调通 → 切单板方案（AX7020 + 摄像头模块）
> **止损点 3（10 月中）**：Transformer 量化精度掉太多 → 切 CNN 模型，保留注意力模块（SENet 风格）
> 宁可"完成度高的系统"冲国二，不要"半吊子 Transformer"拖死。
